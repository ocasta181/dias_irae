# Alternative image-generation models

Research checked against provider documentation on 2026-10-04. These are three current frontier candidates for this project, not a claim that one model wins every image benchmark. None has been tested on Guarin yet; the recommendations below are judgments from documented capabilities.

The latest user review prefers the texture of S13 and S17, but rejects the camera progress and the drift toward human proportions. Keep an exaggerated oversized head, tiny body and short limbs. Preserve the full-face greathelm, straight sword, muted wine cloth and dark textured cartoon finish. Texture preference is not full concept approval. Pause generation with the built-in tool while selecting an alternative.

## Proposed evaluation

Start with Nano Banana Pro. Use a new generation with the same written character brief; preserve the preferred texture and deliberately large-head/small-body silhouette. Record the exact provider model, input mode, prompt, input references, requested camera and output dimensions. Do not describe a text-requested angle as a measured output angle.

A new simple three-dimensional (3D) blockout would give us a fixed camera and exaggerated proportions as a composition guide. That guide can be newly rendered at the required elevation, rather than transforming the old concept. The image model supplies the illustrated surface finish; the guide supplies explicit geometry. This is a proposed next workflow, not an implemented or approved production pipeline.

The first test must visibly change helmet-crown projection, shoulder/boot visibility and body foreshortening while retaining the exaggerated proportions. Review that small pilot before selecting a production generator. No sprites or remaining cast concepts should be generated across the existing approval gates.
