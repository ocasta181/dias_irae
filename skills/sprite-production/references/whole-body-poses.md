# Whole-body drawing controlled by skeletal poses

Use this method for organic characters unless the project has selected another proven authoring method. The output is a complete character in every frame. The control drawing is not final artwork.

## 1. Establish the intact base

Inputs: approved anatomy, style and gameplay references; camera; proportion bounds; canonical canvas and root.

Draw one complete animal/person. Inspect the neck, torso, limb topology, silhouette, face and scale before using it as a generation reference. Preserve raw bytes and record whether this is a provisional base or user-approved identity. Do not use a rejected assembly as the base.

When an animal must share a human character's exaggerated proportions, make the selected character the primary proportion reference. A species photograph supplies species features, not natural body ratios. Define measurable head-to-torso and leg-to-body bounds in the project contract; draw these envelopes into the controls. Compare the actual painting with the selected character at gameplay scale before drawing animation. A good anatomical likeness does not excuse drifting back to realistic proportions.

Output: one intact base image, its source record and canonical registration. A valid alpha mask or contact report cannot approve this design.

## 2. Draw anatomy-aware controls

Inputs: base, measured anchors and motion plan.

Choose joints appropriate to the animal. A canine foreleg needs shoulder, elbow, carpus and paw; its hind leg needs hip, stifle, hock and paw. Do not give a wolf a two-segment human leg. Establish bend directions and verify reachability before painting.

Compute projected joint and contact positions for every frame. Identify each anatomical side and distinguish stance, swing and occlusion. Use different leg colors; draw hidden limbs with dashed lines. Include a body/spine contour and head/neck connection so foot control cannot leave the torso unconstrained.

Output: skeletal diagrams and a machine-readable table with stable frame IDs. Contact checks here validate planned motion only.

## 3. Make the handoff explicit

Supply the exact intact base and the actual guide image as separate references. Add approved style/environment images when needed. State which reference controls identity, medium, geometry and scale.

Embed the numerical rows in the prompt. Include canvas size, page layout, fixed root, frame IDs, holds, planted paws and all joint positions. A tool cannot read an unattached repository file.

Request complete painted characters with a continuous neck and torso. The agent fills the posed silhouette; it must not paint separate heads, legs, torsos or a component kit. Require stable coat/gear markings, believable overlap and unchanged proportions.

Exclude all guide lines, colors, labels, roots and ground marks from final art. Require true alpha and unclipped figures. State that the guide grid is the output registration, not a suggestion to rearrange characters.

Output: bounded chronological whole-body drawings, original request, input hashes and original generated bytes. Begin with a complete walk/idle pilot; do not generate the entire inventory yet.

## 4. Measure the drawings independently

Inspect actual dimensions and layout. Use one documented page-level transform to map output cells to logical coordinates. Do not crop each animal and rescale it to a common silhouette height. Reject unexplained registration, incorrect layouts or drawings spilling into adjacent cells.

Annotate actual paws, joints and torso/head attachments from the painted pixels. State measurement uncertainty and occluded landmarks. Planned coordinates are not measured coordinates. Do not give an invisible paw an invented measured position.

Recompute world contacts from these measurements and actual runtime root travel. Keep the numerical result separate from visual anatomy, texture, silhouette and timing judgments.

Output: measurements, contact report and frame-specific defects. Pass only the checks that have evidence.

## 5. Inspect the exported pilot in motion

Use the same atlas the application loads. Check normal speed, slow speed, reduced size, contrasting backgrounds and the loop boundary. Exercise start, arbitrary-phase stop, turn, interruption and recovery. Inspect visible weight transfer, not only endpoint coordinates.

A coherent whole animal is mandatory. Disconnected-looking necks, distorted legs, flickering fur or an unreadable gait fail even if contacts are numerically correct. Alpha connectivity can catch separated pieces; it cannot establish good anatomy or convincing overlap.

Output: playback evidence and a clear pilot verdict. Expand only after the pilot meets visual and motion budgets and any existing approval gate. After two targeted failures, change the control hypothesis or report the tool's limitation. Do not replace whole-body art with assembled parts merely to make a coordinate test pass.
