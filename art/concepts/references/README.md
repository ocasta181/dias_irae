# Preserved generation input

`e01-greathelm-input.jpg` is the unchanged Commons rendition actually supplied as a helmet-shape reference for S07–S12. It is retained separately from the equipment board’s downloaded rendition so records point to the exact input used.

Source: [Topfhelm DHM photograph](https://commons.wikimedia.org/wiki/File:Topfhelm_DHM.jpg). Photograph: Ulrich Waack, January 2011; levels adjustment: Hohum, July 2011. [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The medieval object is public domain; the photograph has its own license. No changes were made to the saved download. Per-generation records contain its file hash.

S14 and S15 were drawn from scratch using written briefs only; neither used this or any other image input.
