# Gameplay-screen review manifest

**24 reference-based explorations** follow the selected source order S49 / S13 / S15 / S01: three Grok and three built-in screens per exact original character. Six independent scene prompts per source explore navigation, defense, refuge, traversal, household interaction and investigation. The original character files are unchanged and were actual generator inputs; no failed gameplay image was supplied.

All 24 current images and one excluded duplicate-helmet trial were inspected. 13 candidates await user review; 11 Grok candidates are explicitly marked `revise` for camera, anatomy or gameplay framing failures. This is a comparison, not a declaration that every model result satisfies the brief. Source identity is substantially better preserved than G01–G04; exact camera calibration, production actor scale and fine costume consistency remain unapproved.

Every Grok call used one native `image_edit` in a fresh session. Every built-in call explicitly supplied the corresponding source path. Original bytes, dimensions, exact prompts, reference hashes and assessments are recorded. One Grok capacity failure was retried; G05 was revised from its original source to remove a duplicate helmeted neighbor. An attempted additional mood-board camera upload was blocked by automatic approval review before execution; no extra image was uploaded. The successful calls use only the exact selected character files.

Use [the gallery](index.html) to rank, accept/reject and comment. **Save review** writes directly here with a dated backup and no file picker. Review notes distinguish parent observations from user approval. No sprites or game level have been implemented.
